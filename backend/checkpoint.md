# Checkpoint — job portal (FastAPI 0.115.6 / Python 3.13.5 / PostgreSQL 17.2)

Project root: repository root (this directory).
Full functional spec: kept outside the repo (summarised in this file).
Stack is an immutable contract: fastapi==0.115.6, Python 3.13.5, SQLAlchemy 2.x + psycopg v3 (`postgresql+psycopg://`), PostgreSQL via compose image `postgres:17.2` exactly. No ORM alternatives, no Alembic (idempotent init_db).

## Conventions (binding for every file)
- Layers: `app/routers` (thin) -> `app/services` (business logic, classes/functions, no HTTP objects except AppError) -> `app/models` (SQLAlchemy 2 `Mapped[]` style) ; `app/schemas` pydantic request bodies; `app/core` infra. Logger: `logging.getLogger(__name__)`; never print. No bare/blanket `except`.
- API prefix `/api/v1` applied ONLY in main.py (`include_router(r, prefix="/api/v1")`); routers declare paths WITHOUT prefix (e.g. `/jobs/search`). Routers never repeat `/api/v1`.
- Python 3.13: use `StrEnum`, `X | None`. All DB columns UUID pks (`uuid.UUID`, default uuid4), timestamps `DateTime(timezone=True)` UTC-aware (`datetime.now(timezone.utc)`), `created_at/updated_at` on main tables. Postgres ARRAY(Text) for list-of-string columns that are filtered (job locations, required_skills, preferred_skills, profile preferred_locations).
- Enums live in `app/models/enums.py` (StrEnum, stored as VARCHAR via `Enum(..., native_enum=False)` or plain String): UserRole{JOB_SEEKER,RECRUITER,ADMIN}; CompanyStatus{PENDING,APPROVED,REJECTED,BLOCKED}; CompanyType{CORPORATE,STARTUP,MNC,GOVERNMENT,CONSULTANCY}; JobStatus{DRAFT,PENDING_REVIEW,ACTIVE,PAUSED,CLOSED,EXPIRED,REJECTED}; JobType{PERMANENT,CONTRACT}; EmploymentType{FULL_TIME,PART_TIME}; WorkMode{ONSITE,REMOTE,HYBRID}; ApplicationStatus{APPLIED,VIEWED,SHORTLISTED,INTERVIEW_SCHEDULED,OFFERED,HIRED,REJECTED,WITHDRAWN}; Visibility{ALL_RECRUITERS,APPLIED_ONLY,HIDDEN}; AlertFrequency{instant,daily,weekly} (lowercase values exactly); QuestionType{TEXT,YES_NO,MULTIPLE_CHOICE}; InterviewMode{VIDEO,PHONE,IN_PERSON}; WorkStatus{FRESHER,EXPERIENCED}; ReportReason{FAKE,SPAM,MISLEADING}; ReviewStatus{PENDING,APPROVED,REJECTED}; InterviewResponse{CONFIRM,RESCHEDULE}. `app/schemas/common.py` re-exports these + `CamelModel` (alias_generator=to_camel, populate_by_name=True).
- JSON output is camelCase dicts built by serializer functions in routers/services (NOT ORM objects). Success: `return ok(data)` / `return paged(items, page, page_size, total, facets=None)` — both return a JSONResponse with the envelope; datetimes encoded ISO-8601 UTC `...Z`, dates `YYYY-MM-DD`. Create endpoints return `ok(data, status_code=201)`.
- Request bodies: pydantic models subclassing CamelModel in `app/schemas/<group>.py` (one file per router group: auth.py, profile.py, seeker.py, recruiter.py, admin.py, messaging.py). Query params for pagination: `page` (>=1, default 1), `pageSize` (default 20, max `settings.max_page_size`=100) via `page_params` dependency. Sort param `sort` (+ `order=asc|desc` where useful).
- Router inclusion order in main.py (matters for static-before-param): common, auth, seeker, profile, recruiter, recruiter_jobs, admin, public. (seeker holds /jobs/saved, /jobs/recommended, /jobs/based-on-searches static routes; public holds /jobs/search then /jobs/{id}; within public, /jobs/search is declared first.) Static routes in seeker therefore precede public `/jobs/{id}`.
- Validation: path `{id}` params are `uuid.UUID`-typed; invalid UUID -> 400/422 VALIDATION_ERROR envelope (global handler) — never 500.
- Mobile regex `^\+?[0-9]{10,15}$`; passwords min 8 chars w/ letter+digit.
- Soft delete: queries on User/Job/Company must filter `deleted_at IS NULL`.
- Quota/counters: Company.jobs_posted incremented when a job first leaves DRAFT (publish -> ACTIVE or PENDING_REVIEW); quota check `jobs_posted >= job_quota` -> 403 QUOTA_EXCEEDED. Admin approval doesn't re-count.
- Screened-out application: status stays APPLIED, `screened_out=True`, `screen_reason` set.
- Application state machine (ALLOWED_TRANSITIONS): APPLIED->{VIEWED,SHORTLISTED,REJECTED,WITHDRAWN}; VIEWED->{SHORTLISTED,REJECTED,WITHDRAWN}; SHORTLISTED->{INTERVIEW_SCHEDULED,OFFERED,REJECTED,WITHDRAWN}; INTERVIEW_SCHEDULED->{SHORTLISTED,OFFERED,REJECTED,WITHDRAWN}; OFFERED->{HIRED,REJECTED,WITHDRAWN}; HIRED/REJECTED/WITHDRAWN terminal. Illegal -> 409 `INVALID_TRANSITION`.
- Env-based settings in `app/config.py` -> `settings` (pydantic-settings; DATABASE_URL and JWT_SECRET REQUIRED, no default -> startup fails). Attribute names (pinned): database_url, jwt_secret, jwt_algorithm, access_token_minutes(15 default 30), refresh_token_days, cors_origins(list), free_email_domains(list), max_resume_mb, max_resume_bytes(property), upload_dir, job_expiry_days(30), default_job_quota(10), demo_credits(50), rate_limit_enabled, rate_limit_login, rate_limit_otp, rate_limit_search, rate_limit_window_seconds, otp_ttl_minutes, otp_length(6), expose_dev_codes(bool: when true auth endpoints add `devOtp`/`devToken` to responses; dev only), scheduler_enabled, expiring_soon_days(3), max_page_size(100), default_page_size(20), log_level, site_url, email_sender("log"), otp_sender("log"), seed_admin_password etc. env var = upper-case of attr.
- Error codes: VALIDATION_ERROR(400/422->use 422 for schema validation, 400 for malformed JSON code MALFORMED_BODY), UNAUTHORIZED 401, FORBIDDEN 403, NOT_FOUND 404, METHOD_NOT_ALLOWED 405, CONFLICT 409, INVALID_TRANSITION 409, DUPLICATE_APPLICATION 409, QUOTA_EXCEEDED 403, INSUFFICIENT_CREDITS 402, RATE_LIMITED 429, INTERNAL_ERROR 500, JOB_CLOSED 400, BAD_REQUEST 400.
- Files: uploads under `settings.upload_dir`; resumes at `<upload_dir>/resumes/<user_id>/<uuid>.<ext>` (never public); public images at `<upload_dir>/{logos,banners,photos}/<name>` served by `GET /files/{kind}/{filename}` (common router); stored URL `/api/v1/files/<kind>/<name>`.
- Demo seed credentials (README + seed): admin `admin@jobportal.demo` / `Admin@12345`; recruiters `recruiter1@technova.com` (TechNova Solutions), `recruiter2@greenleaf.in` (GreenLeaf Consulting, type CONSULTANCY), `recruiter3@finserve.co.in` (Finserve Bank) all `Recruiter@123`; seekers `seeker1@example.com`..`seeker20@example.com` all `Seeker@12345`. Seed users are email+mobile verified.
- Tests: pytest vs REAL Postgres. conftest derives DB `<name>_test` from DATABASE_URL (creates if missing, drops/recreates schema per session), sets env before importing app; RATE_LIMIT_ENABLED=false except rate-limit test; SCHEDULER_ENABLED=false.
- requirements.txt (runtime) + requirements-dev.txt (`-r requirements.txt`, pytest, httpx); Dockerfile: runtime stage installs only requirements.txt; `--target test` stage adds requirements-dev.txt.

## Pinned cross-module signatures (db is `sqlalchemy.orm.Session`)
core/errors.py: `AppError(status_code, code, message, details: list[dict]|None=None)`; subclasses `BadRequestError(message, code="BAD_REQUEST", details=None)`, `UnauthorizedError(message="Authentication required")`, `ForbiddenError(message="Forbidden")`, `NotFoundError(message="Resource not found")`, `ConflictError(message, code="CONFLICT")`, `RateLimitedError`; `register_handlers(app)` (HTTPException handler MUST preserve exc.headers so 405 keeps `Allow`).
core/responses.py: `ok(data=None, status_code=200)`, `paged(items, page, page_size, total, facets=None)`, `PageParams(page, page_size, offset)` dataclass + `page_params` Depends (query `page`, `pageSize`), `paginate(db, stmt, params) -> (rows: list, total: int)` (stmt = `select(Entity)` with order_by; counts via subquery, applies limit/offset; for `select(Entity)` returns scalars), `csv_response(filename, header: list[str], rows: Iterable[list]) -> StreamingResponse/Response`.
core/security.py: `hash_password, verify_password, create_access_token(user)->(token, expires_in_seconds), decode_token(token)->dict (raises UnauthorizedError), new_refresh_token()->str, hash_token(raw)->sha256 hex, generate_otp()->str`.
core/deps.py: `get_current_user` -> User (401 if missing/invalid/blocked/deleted... blocked -> 403 ACCOUNT_BLOCKED? NO: use 401 for missing/invalid, 403 for blocked); `optional_user` -> User|None (absent header -> None; bad token -> 401); `require_roles(*roles: UserRole)` -> dependency returning User (403 otherwise); `RecruiterContext(user, company, is_company_admin)` dataclass + `recruiter_ctx` dependency (role RECRUITER with company, else 403); also `get_db` re-exported from app.db. Also updates `user.last_active_at` at most every 5 min.
core/ratelimit.py: `rate_limit(name: str)` dependency factory, names "login","otp","search"; `reset_rate_limits()` for tests.
services/senders.py: `EmailSender.send(to, subject, body)`, `OtpSender.send(mobile, code)`, `get_email_sender()`, `get_otp_sender()`.
services/notifications.py: constants `Category` StrEnum {APPLICATION_VIEWED, APPLICATION_SHORTLISTED, INTERVIEW_SCHEDULED, INTERVIEW_RESPONSE, STATUS_CHANGE, JOB_ALERT, RECRUITER_APPROVED, RECRUITER_REJECTED, JOB_APPROVED, JOB_REJECTED, JOB_EXPIRING, NEW_APPLICANT, PROFILE_VIEWED, NEW_JOB_FROM_COMPANY, MESSAGE, SYSTEM}; `notify(db, user_id, category, title, body, email=True, data=None) -> Notification|None` (respects NotificationPreference; adds row, emails via sender when email=True and pref email_frequency allows; does NOT commit — caller commits).
services/job_index.py (owned by models builder): `reindex_job(db, job_id)` runs UPDATE setting `search_vector` = setweight(title,'A') || setweight(skills,'A') || setweight(company name,'B') || setweight(description/responsibilities,'C'); `reindex_all(db)`.
services/matching.py (group profile): `match_score(job_skills: list[str], candidate_skills: list[str]) -> {"percentage":int,"matchingSkills":[...],"missingSkills":[...]}` (case-insens.; empty required -> 100); `candidate_skill_names(db, user_id) -> list[str]`; `profile_completeness(db, user_id) -> {"percentage","missingSections","suggestions"}`.
services/search.py (group public): `JobSearchFilters` dataclass; `search_jobs(db, filters, page, page_size, sort, user) -> (items: list[dict], total: int, facets: dict)`; `serialize_jobs(db, jobs: list[Job], user: User|None, query: str|None=None) -> list[dict]` (batched list-object serializer: company rating avg of APPROVED reviews, isSaved, isApplied, snippet); `expand_synonyms(db, q) -> list[str]`; `suggest(db, type, q, limit=10) -> list`; `recommended(db, user, page, page_size) -> (items, total)`; `based_on_recent_searches(db, user, page, page_size) -> (items,total)`; `similar(db, job, user=None, limit=10) -> list[dict]`; `company_jobs(db, company_id, user, page, page_size, exclude_job_id=None) -> (items,total)`.
services/alerts.py (group seeker): `match_alerts(db, since: datetime, frequency: AlertFrequency) -> list[tuple[JobAlert, list[Job]]]`; `dispatch_alerts(db, frequency, now=None) -> int` (notifications sent; updates last_sent_at; skips paused; commits); `notify_followers_of_job(db, job) -> int` (does not commit).
services/applications.py (group seeker): `ALLOWED_TRANSITIONS`; `change_status(db, application, new_status: ApplicationStatus, actor: User, message: str|None=None, notify_candidate=True) -> Application` (validates, writes StatusHistory, updates timestamps, notifies candidate with proper Category, no commit); `apply_to_job(db, user, job, *, resume_id, cover_note, answers: list[dict], expected_ctc, notice_period) -> Application` (answers: `{"questionId","answer"}`; no commit — caller commits; raises ConflictError(code DUPLICATE_APPLICATION) / BadRequestError(code JOB_CLOSED)); `screen_answers(questions, answers) -> (screened_out: bool, reason: str|None)`; `serialize_application(db, app, view="seeker"|"recruiter") -> dict`.
services/jobs_lifecycle.py (group recruiter-jobs): `expire_jobs(db, now=None) -> int` (commits); `notify_expiring_soon(db, now=None, days=None) -> int` (commits); publish/pause/close/duplicate/refresh/reindex.
services/credits.py (group recruiter-company): `spend(db, company, amount, reason, user_id=None, ref_type=None, ref_id=None) -> CreditLog` (402 INSUFFICIENT_CREDITS; row-locks company; no commit); `unlock_contact(db, company, candidate_id, user) -> (ContactUnlock, charged: bool)`; `is_unlocked(db, company_id, candidate_id) -> bool`; `add_credits(db, company, amount, reason, user_id=None)`.
services/candidate_search.py (group recruiter-company): `parse_boolean`, `search_candidates(db, company, filters, page, page_size) -> (items,total)`, `mask_candidate`.
Messaging eligibility (common router): application of candidate to a job of the recruiter's company OR ContactUnlock OR CandidateInvite (model in models/company.py) exists.
Notification service callers: routers/services call `notify(...)` then commit.
